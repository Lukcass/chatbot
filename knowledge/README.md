# Biblioteca agronómica (RAG) — VACÍA, pendiente
Coloca aquí documentos validados en `.md` (un tema por archivo, párrafos separados por línea en blanco).
La primera línea de cada archivo debe citar la fuente (autor, año, URL). Papanauta (modo IA) cita el nombre del archivo.
No añadas texto sin fuente verificable. Para PDF: conviértelos a texto antes (ver README principal, paso 6).
